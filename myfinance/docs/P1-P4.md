# MyFinance — P1 sampai P4

## P1 — Minimal Tiga Alternatif Tema

1. MyFinance — pencatatan keuangan pribadi mahasiswa.
2. StudyTrack — pengelolaan jadwal belajar dan tugas mahasiswa.
3. SmartMeal — pencatatan menu makan dan anggaran makan mahasiswa.

Tema yang dipilih: **MyFinance**.

## P2 — Tema yang Mengerucut

### Deskripsi Masalah
Mahasiswa sering mencatat pemasukan dan pengeluaran secara manual di catatan HP atau spreadsheet yang tidak konsisten. Akibatnya, pengguna sulit mengetahui saldo, jumlah pengeluaran, dan kategori pengeluaran terbesar.

### Profil Target Pengguna
Mahasiswa yang ingin mengatur keuangan pribadi dengan aplikasi sederhana.

### Manfaat Aplikasi
- Mencatat transaksi dengan cepat.
- Mengetahui saldo secara otomatis.
- Melihat ringkasan pemasukan dan pengeluaran.
- Mengetahui kategori pengeluaran terbesar.

### Fitur Inti
- Register dan login.
- Dashboard keuangan.
- CRUD transaksi.
- Filter transaksi.
- CRUD kategori.
- Riwayat transaksi terbaru.

### Fitur yang Tidak Dikerjakan
- Integrasi rekening bank/e-wallet.
- Pembayaran dan transfer.
- Investasi dan crypto.
- AI financial advisor.
- Notifikasi WhatsApp/SMS.
- Chart kompleks.

### Kriteria Keberhasilan
Aplikasi dapat login, melakukan CRUD transaksi, menyimpan data di MySQL, menghitung dashboard dengan benar, dan membatasi data berdasarkan user.

## P3 — Dokumen Arsitektur

```text
Browser
  ↓
React + TypeScript + Vite + Tailwind
  ↓ REST API / JSON
Node.js + Express + TypeScript
  ↓
Prisma ORM
  ↓
MySQL
```

### Entitas Utama

**User**: Id, Name, Email, PasswordHash, CreatedAt.

**Category**: Id, Name, Type, CreatedAt.

**Transaction**: Id, UserId, CategoryId, Type, Amount, Description, TransactionDate, CreatedAt, UpdatedAt.

### Aliran Data Tambah Transaksi

```text
Form React
 → POST /api/transactions
 → Auth Middleware
 → Zod Validation
 → Transaction Service
 → Prisma
 → MySQL
 → JSON response
 → React refresh
```

### API

```text
POST /api/auth/register
POST /api/auth/login
POST /api/auth/logout
GET  /api/auth/me
GET/POST /api/categories
PUT/DELETE /api/categories/:Id
GET/POST /api/transactions
GET/PUT/DELETE /api/transactions/:Id
GET /api/dashboard
```

### Security

- Password di-hash dengan bcrypt.
- JWT disimpan pada HttpOnly cookie.
- `Helmet` untuk HTTP security headers.
- `CORS` dibatasi ke frontend URL.
- Rate limit pada endpoint authentication.
- Validasi backend dengan Zod.
- Database hanya diakses backend.
- Query menggunakan Prisma.
- Setiap query transaksi menggunakan UserId agar data antar-user terpisah.
- Secret database/JWT hanya di `.env` dan `.env` tidak di-commit.

## P4 — Implementasi dengan Bantuan ChatGPT

Kode proyek dibuat berdasarkan spesifikasi P3. Hasil generasi dipelajari melalui struktur folder, route, controller, service, Prisma schema, shared types, dan komponen React.

Pengujian yang perlu dilakukan mahasiswa:

1. `npm install`
2. `npm run db:up`
3. `npm run db:migrate`
4. `npm run db:seed`
5. `npm run dev`
6. Buka frontend pada `http://localhost:5173`.
7. Pastikan backend hidup pada `http://localhost:4000/health`.
8. Uji register/login.
9. Uji tambah, edit, filter, dan hapus transaksi.
10. Pastikan perubahan frontend tersimpan di MySQL melalui API.
